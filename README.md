# 어떤원두 회사 소개 웹사이트

> 수업용 가상 회사입니다. 등장하는 회사·인물·수치는 모두 지어낸 것입니다.

취향 질문과 시음 후기로 나에게 맞는 커피를 골라 매달 집으로 보내주는 월간 커피 구독 서비스, **어떤원두**의 소개 사이트입니다.
컨셉은 "물음표에서 시작하는 취향 탐험"입니다.

## 페이지 구성

| 경로 | 내용 |
| --- | --- |
| `index.html` | 메인 (히어로, 서비스 3단계, 숫자로 보는 어떤원두) |
| `taste-test/` | 취향 테스트 체험 (규칙 기반 목업) |
| `beans/` | 원두 소개 · 맛 비교 |
| `subscription/` | 구독 안내 (방식 · 배송 주기 · 요금, 예시 데이터) |
| `story/` | 브랜드 스토리 · 회사 기본 정보 |

공통 스타일은 `css/`, 스크립트는 `js/`에 있습니다.

## 실행

빌드 없이 정적 파일로 동작합니다. `index.html`을 브라우저로 열거나 로컬 서버를 띄우세요.

```
python -m http.server 8000
```

## 주의

- 실제 결제·로그인·추천 알고리즘은 없습니다. 취향 테스트와 구독 버튼은 소개용 체험입니다.
- 요금표·배송 주기·원두 목록은 예시 데이터입니다.
- 사내 지표·내부 이슈는 사이트에 넣지 않습니다. (`CLAUDE.md` 7번 참고)
